✨ New Features Added:

1. Pod Map & getPodLead() Function

Fixed mapping of OID to Pod Lead (O38844→Gautham, O16907→Srigandh, O36952→Himanshu)

2. Settings Toggles

• includePodLeadInExports - adds PodLead column in CSV exports
• includePodLeadInCopyLogs - appends "[Lead: Name]" to copy log entries

3. Remove Analyst Function

Idempotent function to remove an analyst from tracking (accessible via 🗑️ Remove button when viewing individual analyst)

4. Copy Queue + Names Button

New "📋 Queue+Names" button groups analysts by queue state without including lead info

5. Conditional Pod Lead in Exports

Export CSV conditionally includes PodLead column based on settings toggle

6. Conditional Pod Lead in Copy Logs

Copy operations conditionally append lead info like "[Lead: Gautham Leeladhar Kunder]"
